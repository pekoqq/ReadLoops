# ReadLoops UI/UX 深度进化实施计划

> **参考案例**：Reader App (iOS风格毛玻璃阅读器)、lucid-reader (glass helper)、Foliate (沉浸式阅读)、Apple Books (专注模式)
> **设计原则**：全局毛玻璃统一、GPU加速动画、交互一致性、专注无干扰
> **不做**：番茄钟

## 任务 1：整体 UI 玻璃质感 + 动画优化

### 目标
全局统一毛玻璃效果，所有面板/卡片/弹窗使用一致的玻璃质感；动画用 GPU 加速，60fps。

### 设计参数（参考 lucid-reader + 2025 glassmorphism 最佳实践）

```css
/* 玻璃质感统一变量 */
:root {
  --glass-bg: rgba(255, 255, 255, 0.06);
  --glass-bg-strong: rgba(255, 255, 255, 0.1);
  --glass-border: rgba(255, 255, 255, 0.1);
  --glass-border-strong: rgba(255, 255, 255, 0.18);
  --glass-blur: blur(20px) saturate(180%);
  --glass-shadow: 0 8px 32px rgba(0, 0, 0, 0.3);
  --transition-smooth: cubic-bezier(0.32, 0.72, 0, 1);
}

/* 深色模式适配 */
[data-theme="dark"] {
  --glass-bg: rgba(30, 30, 35, 0.7);
  --glass-bg-strong: rgba(40, 40, 45, 0.8);
  --glass-border: rgba(255, 255, 255, 0.08);
  --glass-border-strong: rgba(255, 255, 255, 0.15);
}
```

### 实施步骤

1. **CSS 变量统一**：在 `style.css` 顶部定义玻璃质感变量，替换现有零散的 rgba 值
2. **侧边栏玻璃化**：`.sidebar` 加 `backdrop-filter: var(--glass-blur)` + `background: var(--glass-bg)` + 右边框
3. **顶部工具栏玻璃化**：`.toolbar` 加同样的毛玻璃效果 + 底边框
4. **卡片玻璃化**：`.article-item`、`.vocab-item`、`.test-option` 统一用 `--glass-bg` + `--glass-border`
5. **弹窗/浮层玻璃化**：`.modal-content`、`.article-detail-popup`、`.lookup-panel` 加毛玻璃
6. **页面切换动画**：`#reader` 内容切换时用 `opacity + transform` 淡入，不用 `display` 切换
7. **卡片悬停动效**：`transform: translateY(-2px)` + 边框变亮 + 阴影加深，`transition: all 0.2s var(--transition-smooth)`
8. **按钮点击反馈**：`:active { transform: scale(0.97) }`
9. **加载动画**：生成文章时显示骨架屏（3行灰色条 + 脉冲动画）

### 涉及文件
- `app/web/css/style.css`（主要）
- `app/web/js/app.js`（页面切换动画、加载状态）

### 实施步骤

6. **侧栏展开时主内容区**：可选：主内容区 `opacity: 0.7` 或 `transform: scale(0.99)`，聚焦侧栏

## 任务 5：FSRS 调度深度整合

### 目标
FSRS 真正驱动学习流程：文章生成选词、阅读行为更新、每日复习队列、遗忘曲线可视化。

### 核心逻辑

#### 5.1 文章生成选词（FSRS 驱动）
- 生词选择优先级调整：
  1. 今天到期复习的词（`srs_due <= now`）— 最高优先级
  2. 快到期的词（`srs_due` 在未来 3 天内）— 高优先级
  3. 记忆强度低的词（`srs_stability < 10`）— 中优先级
  4. 生词本中的新词 — 低优先级
- 每篇文章中，60% 是复习词（到期/快到期），40% 是新词

#### 5.2 阅读行为更新 FSRS
- 阅读完一篇文章后，根据行为更新每个目标词的 FSRS：
  - 查词了 → 难度上调（`srs_difficulty += 0.1`），稳定性不变
  - 没查词 → 难度不变，稳定性根据阅读时间微调
  - 高亮标记了 → 视为重点词，下次复习间隔缩短
- 阅读时间 < 文章词数/100（读太快）→ 不更新 FSRS（可能没认真读）
- 阅读时间 > 文章词数/20（读太慢）→ 难度上调

#### 5.3 测试结果更新 FSRS
- 测试正确 → 按 FSRS 算法更新间隔（`srs_stability *= 1.2`，`srs_due = now + stability`）
-  测试错误 → 重置间隔（`srs_stability = max(1, stability * 0.5)`，`srs_lapses += 1`，`srs_due = now + 1天`）
- 反应时间 < 3秒 → 记忆牢固，稳定性额外 +10%
- 反应时间 > 10秒 → 记忆不牢，稳定性 -10%

#### 5.4 每日复习队列
- 进入应用时计算"今天该复习 X 个词"
- 侧边栏或统计页显示复习队列
- 一键开始复习测试（只考今天到期的词）

#### 5.5 遗忘曲线可视化
- 生词详情浮层显示：
  - 记忆强度条（0-100%）
  - 下次复习时间
  - 已复习次数
  - 遗忘次数
  - 最近复习时间

### 实施步骤

1. **FSRS 更新函数**：在 `app/services/srs.py` 中实现 `update_after_reading()`、`update_after_test()` 函数
2. **文章生成选词**：修改 `app/services/ai.py` 的 `_select_new_words()`，加入 FSRS 优先级
3. **阅读结束更新**：在阅读 session 结束时（关闭文章/切换文章），调用 `update_after_reading()`
4. **测试结果更新**：修改 `app/services/smart_test.py` 的 `submit_test_result()`，加入 FSRS 更新
5. **每日复习队列 API**：`GET /api/words/review-due`，返回到期复习的词列表
6. **前端复习入口**：侧边栏加"今日复习 X 词"按钮，点击开始复习测试
7. **生词详情 FSRS 可视化**：在 `renderVocabDetail()` 中加入记忆强度条、复习时间等
8. **统计页 FSRS 概览**：统计页显示"待复习词数"、"今日已复习"、"平均记忆强度"

### 涉及文件

- `app/services/ai.py`（选词逻辑）
- `app/services/smart_test.py`（测试结果更新）
- `app/api/words.py`（复习队列 API）
- `app/web/js/app.js`（复习入口、FSRS 可视化）
- `app/web/css/style.css`（记忆强度条样式）
